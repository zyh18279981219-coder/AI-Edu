# AI-Education 前端原型 - 使用说明

## 📋 项目概述

这是AI-Education智能教育系统的前端原型，包含学生端和教师端两个主要模块。

## 🎯 系统架构

```
AI-Education
├── 学生端 V1 (基础版)
├── 学生端 V2 (增强版：诊断智能体 + 个性化路径推荐)
└── 教师端 (含课程数字孪生)
```

## 🚀 快速开始

### 1. 打开入口页面
用浏览器打开 `index.html`，你会看到3个卡片：
- 👨‍🎓 学生端 V1（蓝色）
- 🚀 学生端 V2（紫色，带NEW标识）
- 👨‍🏫 教师端（绿色）

### 2. 选择要体验的功能
点击对应的卡片即可进入。

## 📚 功能详解

### 学生端 V1（基础版）
**文件**: `student-v1.html`

**功能**:
- 🤖 5E智能学习助手（Engagement → Exploration → Explanation → Elaboration → Evaluation）
- 🕸️ 知识图谱可视化
- 📊 个人能力画像
- 💼 行业资讯与职业规划
- 📝 智能作业管理

**适合**: 体验基础的AI辅助学习功能

---

### 学生端 V2（增强版）⭐ 推荐
**文件**: `student-v2.html`

**包含V1所有功能，额外新增**:

#### 1. 🔍 诊断智能体
**位置**: 顶部导航 → 点击「🔍 诊断」

**功能**:
- **深度能力画像**: 不只是分数，而是分析你的学习风格和能力结构
- **溯源归因链路**: 找出错题的根本原因（知识遗忘/逻辑断层/迁移障碍）
- **动态风险前瞻**: 预测未来3天/7天/14天的学习风险，提供干预建议

**价值**: 深度了解自己的学习状态，精准定位问题

#### 2. 🎯 个性化学习路径推荐
**位置**: 学习中心 → 左侧面板 → 点击「📅 计划」Tab

**功能**:
- **AI路径生成**: 根据你的学习情况，自动生成个性化学习顺序
- **节点管理**: 
  - ✓ 已完成节点（绿色）
  - ● 进行中节点（蓝色，带学习建议和推荐资源）
  - ○ 待学习节点（灰色）
  - ⚠ 补学节点（橙色，系统智能推荐）
  - ◇ 拓展节点（紫色，选学内容）
- **智能建议**: 每个节点都有学习建议、推荐资源、预估时长
- **动态调整**: 可以查看历史版本、调整路径、重新生成

**价值**: 不用自己规划学习顺序，AI帮你安排最优学习路径

**示例**:
```
🎯 AI个性化学习路径
总节点数: 15个 | 已完成: 5个 | 进度: 33% | 预估剩余: 8小时

✓ 1. 大数据概念 [已完成 90%]
✓ 2. 数据特征 [已完成 85%]
● 3. HDFS架构 [进行中 45%]
   💡 建议: 先复习分布式系统基础
   📚 推荐资源: HDFS架构视频、官方文档
   [继续学习 →]
○ 4. MapReduce原理 [待学习]
⚠ 补. 分布式系统基础 [系统推荐补学]
```

### 教师端
**文件**: `teacher.html`

**功能**:
- 📊 数据看板 - 班级整体数据概览
- 👥 学生管理 - 查看和管理学生学习情况
- 🕸️ **课程数字孪生** - 课程级管理视图（重点功能）
- 📚 资源管理 - 管理课程资源
- 📝 作业批改 - 批改学生作业
- 👤 个人画像 - 六维教师画像

#### 🕸️ 课程数字孪生（重点）
**位置**: 教师端 → 顶部导航 → 点击「🕸️ 课程数字孪生」

**功能**:
- **核心指标**: 知识图谱覆盖率92%、资源覆盖率87%、班级掌握度68%、风险等级
- **知识图谱可视化**: 树状结构展示课程章节和知识点
- **班级掌握热力图**: 学生×知识点矩阵，一眼看出哪些学生在哪些知识点上有问题
- **高风险节点识别**: 自动识别班级薄弱知识点，给出教学建议
- **资源网络分析**: 统计资源覆盖情况，推荐需要补充的资源

**价值**: 教师可以全局掌握课程健康度，基于数据做教学决策

**示例**:
```
班级掌握热力图:
学生   | 大数据概念 | HDFS架构 | MapReduce | Spark
张三   |    90     |    45    |    70     |  65
李四   |    85     |    60    |    40     |  55
王五   |    75     |    35    |    65     |  45

高风险节点:
⚠️ HDFS架构 [高风险]
   平均掌握度: 42% | 风险学生: 12人
   建议: 增加实践练习，补充视频资源
```
