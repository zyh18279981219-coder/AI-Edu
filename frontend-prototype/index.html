学生端 V1 智能体优先
Agent-First Learning
强制通过5E智能体进行对话式学习，知识图谱作为辅助资源获取工具，适合需要引导式学习的场景。
  • 5E智能体对话式学习（主界面）
  • 实时5E阶段进度显示
  • 侧边知识点关系网络面板
  • 快速获取PDF/视频资源
  • 学习进度实时追踪
查看原型 → 引导式学习
🚀
学生端 V2 自由选择
Flexible Learning
学生可自由选择学习方式（智能体对话 or 知识图谱浏览），提供更灵活的学习体验和个性化路径推荐。
  • 5E智能学习助手（可选）
  • 诊断智能体（深度能力分析）
  • AI个性化学习路径推荐
  • 知识图谱可视化浏览
  • 行业资讯与职业规划
  • 智能作业管理系统
查看原型 → 自主式学习
👨‍🏫
教师端
Teaching Dashboard
数据驱动的教学管理平台，提供班级数据看板、学生学习监控、课程数字孪生等功能。
  • 班级数据看板与分析
  • 学生学习行为监控
  • 课程数字孪生（知识图谱+热力图）
  • 六维教师画像系统
  • 作业批改与资源管理
查看原型 → 教学管理

原型目的
