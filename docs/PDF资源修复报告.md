## 技术细节

### PDF 生成技术栈

- **库**: reportlab 4.5.0
- **字体**: SimSun（宋体）、SimHei（黑体）
- **页面**: A4 (210mm × 297mm)
- **编码**: UTF-8

### 中文字体处理

```python
# 注册 Windows 系统字体
pdfmetrics.registerFont(TTFont('SimSun', 'C:/Windows/Fonts/simsun.ttc'))
pdfmetrics.registerFont(TTFont('SimHei', 'C:/Windows/Fonts/simhei.ttf'))

# 备选方案：CID 字体
pdfmetrics.registerFont(UnicodeCIDFont('STSong-Light'))
```

### PDF 内容模板

每个 PDF 包含以下章节：

1. **标题**（24pt 加粗居中）
2. **学习目标**（16pt 加粗）
3. **核心概念**（16pt 加粗）
4. **原理说明**（16pt 加粗）
5. **应用场景**（16pt 加粗）
6. **常见误区**（16pt 加粗）
7. **小结**（16pt 加粗）
8. **思考题**（16pt 加粗，3个问题）
