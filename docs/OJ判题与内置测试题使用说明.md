# OJ判题与内置测试题使用说明

这份文档用于快速说明：
1. OJ 地址在哪里配置
2. 怎么生成内置测试题
3. 老师和学生怎么用它验证链路是否跑通

## 1. OJ统一配置

统一配置文件在：
- config/app_runtime.json

当前关键字段：
- oj.run_url：OJ接口地址
- oj.timeout_seconds：请求超时秒数
- oj.java_bin：Java运行路径

你只需要改这一处配置，不用再改多个代码文件。

## 2. 一键生成内置测试题

系统已提供内置接口：
- POST /api/homework/assignments/seed-oj-smoke

权限：
- 教师或管理员

作用：
- 自动生成并发布一份代码作业：OJ三语言连通性测试（内置）
- 题目里直接带 Python、C++、Java 参考答案代码
- 测试点为分点计分，便于检查判题链路

说明：
- 如果已存在同名内置题，系统会直接返回已有题目，不会重复创建。

## 3. 本地脚本方式生成（可选）

如果你不想走接口，也可以运行脚本：
- scripts/seed_oj_smoke_assignment.py

用途：
- 向数据库写入同一套内置测试题。

## 4. 教师端怎么用

1. 登录教师端
2. 进入作业列表
3. 找到 OJ三语言连通性测试（内置）
4. 检查题干中是否包含三种语言参考答案

## 5. 学生端怎么验证

1. 登录学生端
2. 打开 OJ三语言连通性测试（内置）
3. 在编辑器选择语言（Python/C++/Java）
4. 将题干中的对应参考代码粘贴提交
5. 查看结果页是否显示每个测试点通过情况和得分

正常现象：
- 能看到测试点列表
- 显示 Passed 或 Wrong Answer
- 最终得分等于通过测试点分值之和

## 6. 常见排查

1. 提交报 Sandbox Error
- 先检查 config/app_runtime.json 里的 oj.run_url 是否可访问。

2. 代码一直不通过
- 先用题干给的参考答案提交一次，确认平台链路没问题，再排查学生代码。

3. Java异常
- 检查 oj.java_bin 是否与容器内实际路径一致。

## 7. 组员一分钟操作清单（合并）

目标：1分钟内完成 OJ 链路自测（教师发布 -> 学生提交 -> 查看结果）。

### 0) 准备（10秒）

1. 确认后端在运行。
2. 确认 OJ 地址可访问：
	- `config/app_runtime.json` 中 `oj.run_url` 正确。

### 1) 教师操作（15秒）

1. 登录教师账号。
2. 生成内置测试题（二选一）：
	- 方式A：调用接口 `POST /api/homework/assignments/seed-oj-smoke`
	- 方式B：运行脚本 `scripts/seed_oj_smoke_assignment.py`
3. 在作业列表确认出现：OJ三语言连通性测试（内置）。

### 2) 学生操作（25秒）

1. 登录学生账号。
2. 打开 OJ三语言连通性测试（内置）。
3. 在题干中复制对应语言参考代码（Python/C++/Java）。
4. 在编辑器选择同样语言，粘贴并提交。

### 3) 验收（10秒）

1. 页面显示测试点 Passed/Wrong Answer 列表。
2. 总分 = 通过测试点分值之和。
3. 教师端可看到提交记录和测试点结果。

---

如果后续要扩展，可在同一配置文件继续增加 OJ 相关参数，保持统一入口。
