# 学生端学习中心 V2 - 中间内容区重排

## 改造目标

本阶段是学习中心整体对齐的第一步：只重排"中间内容区"，把 PDF / 视频 / 在线测验 / 知识总结放回中间 viewer tabs，参考原型 `frontend-prototype/student-v2.html` 的 learning-center 页面。

**目标**：让 `CourseContentView.vue` 的中间内容区更接近原型中的"学习内容工作台"。

**本阶段不改右侧 5E，不接 5E 后端。**

## 改造内容

### 1. 新增 Viewer Tabs

在中间内容区新增四个 tabs：
- **📄 PDF文档**：展示当前知识点的 PDF 资源
- **🎥 视频讲解**：展示当前知识点的视频资源
- **📝 在线测验**：提供测验入口，复用现有测验流程
- **📋 知识总结**：复用右侧 AI 助教的总结功能

### 2. 内容头部

新增内容头部，包含：
- **面包屑导航**：课程 / 章节 / 当前知识点
  - 基于当前选中的 chapter / section / currentNode 计算
  - 安全 fallback 为"当前课程 / 当前章节 / currentNode.name"
- **工具按钮**：
  - 上一个（前端占位，console 输出）
  - 下一个（前端占位，console 输出）
  - 收藏（本地状态）
  - 笔记（前端占位，console 输出）

### 3. PDF 文档面板

- 复用现有 `selectedResourceType === "pdf"` 和 `pdfViewerUrl`
- 如果当前没有 PDF 资源，显示"当前知识点暂无 PDF 文档"
- 不破坏 iframe 显示

### 4. 视频讲解面板

- 复用现有 video 播放逻辑
- 如果当前没有视频资源，显示"当前知识点暂无视频讲解"
- 不破坏 video loading/error 逻辑

### 5. 在线测验面板

- 不把完整 QuizView 搬进来
- 提供一个中间区测验入口卡片：
  - 标题：当前知识点在线测验
  - 描述：围绕当前知识点快速开始测验
  - 按钮：开始测验
  - 点击复用 `openQuiz()`
- 保留几个快捷主题按钮

### 6. 知识总结面板

- 把右侧 summary 逻辑复用到中间区：
  - `summaryTopic`
  - `submitSummary()`
  - `summaryLoading`
  - `summaryText`
  - `summaryError`
- 中间区提供：
  - 总结主题输入
  - "AI生成总结"按钮
  - 总结输出区域
- **右侧 AI 助教的 summary tab 暂时保留**，不删除，避免大改
- 后续阶段再统一右侧为 5E

### 7. 底部操作

在中间内容区底部新增：
- **导出笔记**：如果 `summaryText` 有内容，复制到剪贴板或 console；不强制实现文件下载
- **标记完成**：本地状态提示，不新增接口

### 8. 资源选择逻辑

- 当前 resource chip 保留，位置调整到 viewer tabs 内部（PDF/视频面板上方）
- 选择资源后应能正确影响 PDF/视频面板
- 如果当前选中 PDF 但用户点视频 tab，没有视频资源则显示空状态

### 9. 默认 Viewer Tab

- 如果当前资源包含视频，默认 `activeViewerTab = "video"`
- 否则默认 `activeViewerTab = "pdf"`
- 如果都没有，默认 `activeViewerTab = "summary"`

## 技术细节

### 资源分类逻辑

```typescript
// PDF 资源：不以 http:// 或 https:// 开头
const pdfResources = computed(() => 
  currentResources.value.filter(r => !r.startsWith("http://") && !r.startsWith("https://"))
);

// 视频资源：以 http:// 或 https:// 开头
const videoResources = computed(() => 
  currentResources.value.filter(r => r.startsWith("http://") || r.startsWith("https://"))
);
```

### 默认 Tab 选择逻辑

```typescript
// 根据资源类型设置默认 viewer tab
if (videoResources.value.length > 0) {
  activeViewerTab.value = "video";
} else if (pdfResources.value.length > 0) {
  activeViewerTab.value = "pdf";
} else {
  activeViewerTab.value = "summary";
}
```

### 面包屑更新逻辑

```typescript
function updateBreadcrumb(node: CourseNode) {
  currentCourseName.value = "大数据基础";
  
  // 尝试从 graph 中找到父章节
  for (const chapter of chapterNodes.value) {
    for (const section of sectionNodes(chapter)) {
      if (section.name === node.name) {
        currentChapterName.value = chapter.name;
        return;
      }
      for (const point of knowledgeNodes(section)) {
        if (point.name === node.name) {
          currentChapterName.value = `${chapter.name} / ${section.name}`;
          return;
        }
      }
    }
  }
  
  currentChapterName.value = "当前章节";
}
```
