### 1. 修复 main.css 构建警告

**问题**：`main.css:2407` 附近存在孤立的 `font-weight` 和 `font-size` 声明，导致 CSS 语法错误。

**原因**：在 `.industry-actions .el-button + .el-button` 规则后，有一个孤立的闭合大括号 `}`，后面跟着两行孤立的属性声明。

**修复**：
```css
/* 修复前 */
.industry-actions .el-button + .el-button {
  margin-left: 0 !important;
}
  font-weight: 600;  /* 孤立声明 */
  font-size: 15px;   /* 孤立声明 */
}

/* 修复后 */
.industry-actions .el-button + .el-button {
  margin-left: 0 !important;
}
```

**结果**：✅ 构建时不再出现 CSS 语法警告

### 2. 移除 MyLearningView.vue 中的 eval

**问题**：`MyLearningView.vue` 使用 `eval()` 解析 i18n 数组，导致构建警告和安全风险。

**原因**：
```typescript
const weekdays = eval(t('student.myLearning.weekdays'));
const monthNames = computed<string[]>(()=> eval(t('student.myLearning.monthNames')));
```

**修复**：使用安全的 `JSON.parse` 替代 `eval`
```typescript
// 安全解析 i18n 数组，避免使用 eval
function safeParseI18nArray(value: string): string[] {
  try {
    // 尝试 JSON.parse
    return JSON.parse(value);
  } catch {
    // 如果失败，提供安全的 fallback
    return [];
  }
}

const weekdays = safeParseI18nArray(t('student.myLearning.weekdays'));
const monthNames = computed<string[]>(() => safeParseI18nArray(t('student.myLearning.monthNames')));
```

**结果**：✅ 构建时不再出现 eval 警告

### 3. 优化学习中心 PDF 聊天绑定时机

**问题**：选择 PDF 资源时立即调用 `selectPdfForChat(resource)`，导致点击目录/切换资源时变慢。

**原因**：每次选择 PDF 都会触发后端 API 调用，即使用户不一定会使用聊天功能。

**修复**：改为懒加载策略

#### 3.1 新增 PDF 绑定缓存
```typescript
// PDF 聊天绑定缓存
const boundPdfResources = ref<Set<string>>(new Set());
```

#### 3.2 移除立即绑定
```typescript
// 修复前
async function selectResource(resource: string, index: number) {
  selectedResource.value = resource;
  selectedResourceIndex.value = index;
  
  if (selectedResourceType.value === "pdf") {
    // 立即调用 API
    selectPdfForChat(resource).catch(err => {
      console.warn('PDF选择提示失败，但不影响查看:', err);
    });
  }
}

// 修复后
async function selectResource(resource: string, index: number) {
  selectedResource.value = resource;
  selectedResourceIndex.value = index;
  
  if (selectedResourceType.value === "video") {
    videoLoading.value = true;
  }
  // PDF 不再立即绑定，改为懒加载策略
}
```

#### 3.3 在发送消息时懒绑定
```typescript
async function submitChat() {
  const message = chatInput.value.trim();
  if (!message) return;
  
  // 懒加载：如果当前是 PDF 资源且尚未绑定，先绑定
  if (selectedResourceType.value === "pdf" && selectedResource.value && !boundPdfResources.value.has(selectedResource.value)) {
    try {
      await selectPdfForChat(selectedResource.value);
      boundPdfResources.value.add(selectedResource.value);
    } catch (err) {
      console.warn('PDF 聊天绑定失败，但不影响发送消息:', err);
    }
  }
  
  // 继续发送消息...
}
```

**懒加载规则**：
1. **选择 PDF 时**：只更新 `selectedResource`，不调用 API
2. **发送消息时**：检查当前 PDF 是否已绑定
   - 如果未绑定，先调用 `selectPdfForChat()`
   - 绑定成功后，加入缓存 `boundPdfResources`
   - 绑定失败时，只影响聊天提示，不影响资源查看
3. **缓存机制**：同一个 PDF 只绑定一次，避免重复调用

**结果**：
- ✅ 选择目录/资源时响应更快
- ✅ PDF 查看不受影响
- ✅ 聊天功能正常工作
- ✅ 减少不必要的 API 调用

### 4. 个性化路径面板懒加载

**问题**：`PersonalizedPathPanel` 组件在页面加载时就被引入，即使用户可能不会切换到个性化路径视图。

**修复**：使用 `defineAsyncComponent` 动态加载

#### 4.1 改为异步组件
```typescript
// 修复前
import PersonalizedPathPanel from "./components/PersonalizedPathPanel.vue";

// 修复后
import { defineAsyncComponent } from "vue";

const PersonalizedPathPanel = defineAsyncComponent(() => 
  import("./components/PersonalizedPathPanel.vue")
);
```

#### 4.2 添加 Suspense 和 loading 状态
```vue
<!-- 修复前 -->
<div v-else>
  <PersonalizedPathPanel />
</div>

<!-- 修复后 -->
<div v-else>
  <Suspense>
    <template #default>
      <PersonalizedPathPanel />
    </template>
    <template #fallback>
      <div class="student-learning-v2-loading-state">
        <div class="loading-spinner"></div>
        <p>加载个性化路径中...</p>
      </div>
    </template>
  </Suspense>
</div>
```

#### 4.3 添加 loading 样式
```css
.student-learning-v2-loading-state {

    transform: rotate(360deg);
  }
}
```

**结果**：
- ✅ 只有切换到"个性化路径"时才加载组件
- ✅ 减少初始包大小
- ✅ 提供友好的 loading 状态
- ✅ 个性化路径功能不受影响

## 已知限制

1. **i18n 数组格式**：`safeParseI18nArray()` 依赖 i18n 值为有效的 JSON 数组格式。如果格式不正确，会返回空数组。
2. **PDF 绑定延迟**：首次发送消息时，如果 PDF 未绑定，会有轻微延迟（等待绑定完成）。
3. **个性化路径 loading**：首次切换到个性化路径时，会显示 loading 状态（通常很快）。

## 后续优化建议

### 短期优化（低风险）
1. **图片懒加载**：对课程资源中的图片使用懒加载
2. **虚拟滚动**：课程目录较长时使用虚拟滚动
3. **防抖优化**：搜索、输入等操作添加防抖

### 中期优化（中风险）
1. **状态管理**：使用 Pinia 统一管理课程状态
2. **缓存策略**：课程目录、作业列表等数据添加缓存
3. **预加载**：预加载用户可能访问的下一个资源

### 长期优化（高风险）
1. **SSR/SSG**：考虑服务端渲染或静态生成
2. **Web Worker**：将复杂计算移到 Worker 线程
3. **PWA**：添加离线支持和缓存策略
